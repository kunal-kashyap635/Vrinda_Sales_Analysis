Vrinda Store — 2022 Sales Data Analysis
About

This project analyzes Vrinda Store's 2022 order data to understand sales trends, delivery performance, customer demographics, and channel performance.

Files
Vrinda_Store_Data_Analysis.xlsx — source data & analysis
Vrinda_Store_Messy — raw, uncleaned order data
Vrinda_Store_clean — cleaned dataset used for analysis
Pivot_Analysis — pivot tables + charts (monthly sales, order status, top states, gender, age group, channel)
Report — summary dashboard with key takeaways
Vrinda_Store_Sales_Report.pptx — 10-slide presentation built from the charts above
Key Insights
Total Orders: 31,047 | Total Revenue: ₹2.12 Cr | Avg Order Value: ₹682
March is the peak sales month; volumes taper off toward Q4
92% of orders are delivered successfully
Maharashtra, Karnataka, Uttar Pradesh are the top 3 states by revenue
Women drive 64% of revenue, led by the 19–50 age group (54%)
Amazon is the top channel (35% of orders), followed by Myntra (23%) and Flipkart (22%)
Recommendation

Target women aged 19–50 in Maharashtra, Karnataka, and Uttar Pradesh with focused ads, promotions, and redeemable coupons to grow revenue in this core segment.
