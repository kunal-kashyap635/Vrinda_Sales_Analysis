## 📖 About

This project analyzes Vrinda Store's 2022 order data to uncover sales trends,
delivery performance, customer demographics, and channel performance.

---

## 📁 Files

| File | Description |
|---|---|
| 📊 `Vrinda_Store_Data_Analysis.xlsx` | Source data, pivot tables & charts |
| 🖥️ `Vrinda_Store_Sales_Report.pptx` | 10-slide presentation of the findings |

**Inside the Excel file:**
| Sheet | Contents |
|---|---|
| `Vrinda_Store_Messy` | Raw, uncleaned order data |
| `Vrinda_Store_clean` | Cleaned dataset used for analysis |
| `Pivot_Analysis` | Pivot tables + charts (monthly sales, order status, top states, gender, age group, channel) |
| `Report` | Summary dashboard with key takeaways |

## 📈 Key Insights

<div align="center">

| 🧾 Total Orders | 💰 Total Revenue | 🛒 Avg Order Value |
|:---:|:---:|:---:|
| **31,047** | **₹2.12 Cr** | **₹682** |

</div>

- 📅 **March** is the peak sales month; volumes taper off toward Q4
- 📦 **92%** of orders are delivered successfully
- 🗺️ **Maharashtra, Karnataka, Uttar Pradesh** are the top 3 states by revenue
- 👩 **Women** drive **64%** of revenue, led by the **19–50 age group (54%)**
- 🛍️ **Amazon** leads channels with **35%** of orders, followed by Myntra (23%) and Flipkart (22%)

---

## 🎯 Recommendation

> Target **women aged 19–50** in **Maharashtra, Karnataka, and Uttar Pradesh** with
> focused ads, promotions, and redeemable coupons to grow revenue in this core segment.
